# Evidence is the product

Threadbare is a local browser inspector for saved n8n execution ancestry. Work only in this repository. Modify the existing traversal once and reuse it; keep the CLI contract and status meaning. A JSON pointer in the UI must resolve to the exact value read during traversal. Preserve consumer input, producer output and run, and fan-in branches. Child ancestry and parent recorded pairing are different evidence roles.

Uploaded JSON stays in the browser. Reports contain structural references, pairing metadata and paths, never business JSON. Uploaded data is parsed as JSON, never evaluated. The separate recorded HTTP panel belongs only to the synthetic demo with recorded requests; a custom execution report covers ancestry.

Incomplete evidence must name the specific missing pointer or contract and the next file/action. No workflow editor, instance/API-key connector, network upload, second app or broad framework.
