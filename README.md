# Threadbare

A local execution desk for n8n: follow a returned item, see the saved pairing evidence, and take an ancestry report back to a client.

This new browser application is being built for Kiroween 2026 Costume Contest. The pre-existing auditor and synthetic native recordings are disclosed in [reuse.md](docs/reuse.md). Run boundaries: successful waiting, once-mode Execute Workflow 1.2; a passthrough child trigger; complete matching parent and child API execution responses.

The browser UI is in development. No custom execution has yet been imported by an external operator. The separately recorded wrong-recipient demo uses synthetic customers.
